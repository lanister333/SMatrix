# «Театр ботов» — конвертер новостей Сахалина в диалог жителей

Скрипт `rewriter.py` берёт новость Сахалина из `test-news.json`, отправляет в DeepSeek API с системным промптом «Театр ботов» и получает JSON-массив из 2-3 реплик местных жителей — как если бы они обсуждали эту новость в чате.

## Получить API-ключ DeepSeek

1. Зайдите на https://platform.deepseek.com/
2. Зарегистрируйтесь (email + пароль, или через Google/GitHub)
3. Перейдите в раздел **API Keys** → **Create new key**
4. Скопируйте ключ (начинается с `sk-...`)
5. Пополните баланс (минимум ~$1 — хватает на тысячи запросов)

## Установка

```bash
pip install requests
```

## Запуск

```bash
# 1. Задать API-ключ
export DEEPSEEK_API_KEY="sk-ваш-ключ-здесь"

# 2. Запустить скрипт
cd scripts/theatre-bots
python rewriter.py
```

## Логика работы

1. Читает `test-news.json`
2. Формирует промпт: системный (роль «Театр ботов») + пользовательский (текст новости)
3. Отправляет в DeepSeek API (`deepseek-chat`, `temperature=0.8`)
4. Парсит ответ: поддерживает чистый JSON, markdown-обёртку, объекты-обёртки
5. Валидирует: 2-3 объекта, у каждого `username` и `text`
6. Если невалидно — повторяет (до 3 попыток, задержка 2 сек)
7. Выводит результат в консоль + сохраняет в `test-output.json`

## Персонажи ботов

Скрипт использует системный промпт с заданным списком персонажей:

| Категория | Регистр | Примеры |
|-----------|---------|---------|
| Кириллица | Стандартный | Дизелист, Штурман, Егерь, Ворчун, Михалыч, Хозяйка |
| Кириллица | Нижний | пассажир, свояк, мамочка, кошатница |
| Латиница | Стандарт | Boss, Caesar, Churchill, Plato |
| Латиница | Нижний | driver, hunter, biker, eva, Fox |
| Транслит | Нижний | vovan, sanek, tolyan, ribak, blondinka |

Боты с нижним регистром генерируют текст **строго в нижнем регистре** с 30% вероятностью опечаток.
