## РАЗВЁРТЫВАНИЕ архива SakhMatrix-project-2026-09-25.zip:

1) Скачать архив curl-ом в /home/z/my-project/upload/:
   mkdir -p /home/z/my-project/upload
   curl -L -o /home/z/my-project/upload/sakhmatrix.zip "<прямая ссылка из чата>"
2) Распаковать в /home/z/my-project:
   unzip -o /home/z/my-project/upload/sakhmatrix.zip -d /home/z/my-project
3) cd /home/z/my-project && bun install
4) npx prisma generate
5) Холодный рестарт:
   pkill -9 -f bun; pkill -9 -f next; sleep 2
   bash /home/z/my-project/scripts/start-dev.sh
   (НЕ ИСПОЛЬЗУЙ "nohup bun run dev" напрямую — package.json dev-скрипт
   содержит "| tee dev.log" который убивается при выходе bash, и сервер
   падает через ~3 секунды. start-dev.sh решает через setsid+nohup.)
6) Ждать HTTP 200 от localhost:3000 (~5с).

Если платформа не отдала архив на диск (ошибка «upload/ пусто») —
залить через gofile.io (litterbox/catbox/transfer.sh/0x0.st/file.io/
tmpfiles в прошлых сессиях все упали — 403 Cloudflare или таймауты;
gofile.io — единственный рабочий):

  curl -F "file=@SakhMatrix-project-2026-09-25.zip" \
    https://store1.gofile.io/uploadFile

## ПОЛНЫЙ ПОТОК «Обсудить на форуме» (финальная логика — АВТО-СОЗДАНИЕ)

1) Клик по «💬 Обсудить на форуме» под публикацией
2) Гость → AuthModal; залогинен → POST /api/discuss/<kind>/<cuid> с token
3) Сервер:
   • Если topicId !== null → {redirect: "/forum/topic/<id>"} (без дубликата)
   • Если topicId === null → формирует title/body по правилам блока:
     - recommend → title+text (+ subject как fallback)
     - wheretobuy/gdedeshevle → title+text
     - employers → employer+city + workPeriod+experience+personMention
     - gkh → title + «Проблема: <text>» + «Действия: <actions>»
   • Добавляет ссылку-источник «— из публикации: <origin>/<page>#<anchor>-<id>»
   • Прогоняет moderateNewText
   • Создаёт Topic + первое Message (от имени текущего пользователя)
   • Привязывает topicId к публикации
   • Возвращает {redirect: "/forum/topic/<newId>"}
4) Клиент делает window.location.href = redirect → пользователь в теме
