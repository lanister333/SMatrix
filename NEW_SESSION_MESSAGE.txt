КАК РАЗВЕРНУТЬ АРХИВ:
1) Распаковать в /home/z/my-project
2) bun install
3) npx prisma generate (ОБЯЗАТЕЛЬНО до проверки API — иначе tsc/API сыпят ошибками;
   после бэкапа 2026-09-24 (вечер) — prisma db push уже применён: у RecUsefulVote
   есть колонка kind, так что достаточно generate)
4) Холодный рестарт:
   pkill -9 -f bun; pkill -9 -f next; sleep 2
   (nohup bun run dev > dev-server.log 2>&1 & disown)
   ждать ответа 200 от localhost:3000
